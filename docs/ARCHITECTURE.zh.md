# Gitx 架构

## 概述

Gitx 是一个包含全栈代码仓库平台的单体仓库（monorepo）。

## 使用 Orca 进行多智能体开发

使用 Orca 智能体开发环境（ADE），我们在隔离的工作树中并行开发：

```
+---------------------------------------------------------+
|                    Orca 工作空间                          |
|  +-------------+  +-------------+  +-----------------+  |
|  | 工作树/     |  | 工作树/     |  | 工作树/         |  |
|  |   core      |  |   api       |  |   web           |  |
|  |             |  |             |  |                 |  |
|  | Git 后端    |  | REST API    |  | React 前端      |  |
|  | SSH/HTTP    |  | 认证/PR/    |  | UI 组件         |  |
|  | 协议        |  | 问题追踪    |  | 实时更新        |  |
|  +------+------+  +------+------+  +--------+--------+  |
|         |                |                   |          |
|         +----------------+-------------------+          |
|                          |                              |
|                    +-----+-----+                         |
|                    |  main   |                         |
|                    | 分支    |                         |
|                    +---------+                         |
+---------------------------------------------------------+
```

## 核心组件

### 1. Git 后端（src/backend/git）

- 文件系统上的裸仓库存储
- SSH Git 协议（通过 git-shell 或自定义实现）
- HTTP Smart Git 协议（git-upload-pack、git-receive-pack）
- 钩子管理（pre-receive、post-receive、update）

### 2. API 服务器（src/backend/api）

- 符合 OpenAPI 3.0 规范的 RESTful API
- 基于 JWT 的认证和会话管理
- 仓库 CRUD 操作
- 拉取请求工作流（创建、审查、合并）
- 问题追踪（创建、分配、标签、关闭）
- 第三方集成的 Webhook 系统

### 3. 前端（src/frontend）

- React 19，启用 TypeScript 严格模式
- Vite 用于快速构建和热模块替换
- Tailwind CSS 用于实用优先的样式
- 通过服务器推送事件（SSE）或 WebSocket 实现实时更新
- 带语法高亮的代码查看器（PrismJS 或 Shiki）

### 4. 数据库 schema

- `users` -- 用户账户、SSH 公钥、OAuth 提供商链接
- `repositories` -- 仓库元数据、可见性（公开/私有）、分叉关系
- `pull_requests` -- PR、审查线程、合并状态、CI 检查
- `issues` -- 问题、标签、里程碑、被指派人
- `organizations` -- 团队、成员角色、权限组
