# ADR 001: 项目初始化

## 状态

已采纳

## 背景

我们需要构建一个类似 GitHub 的自托管代码仓库平台。该项目必须满足：

- 基于 MIT 许可证开源
- 使用 Orca ADE 多智能体并行工作流开发
- 面向全球贡献者
- 提供英文和中文双语文档

## 决策

1. **单体仓库结构**：所有组件（后端、前端、CLI、共享类型）位于单个仓库中，便于原子化变更和简化 CI/CD。
2. **MIT 许可证**：最大化采用率，允许商业使用。
3. **Orca ADE 多智能体工作流**：四个专属智能体（`gitx-core`、`gitx-api`、`gitx-web`、`gitx-ops`）在并行工作树中工作。
4. **双语文档**：每份英文文档都有对应的中文翻译（`.zh.md`），以支持中文母语的项目负责人和未来的中文贡献者。
5. **技术栈**：Go/Rust 后端、React 19 前端、PostgreSQL、Redis、Docker。

## 后果

- 正面：关注点分离清晰、并行开发、全球可访问性。
- 负面：单体仓库需要谨慎的依赖管理；双语文档增加了维护开销。
